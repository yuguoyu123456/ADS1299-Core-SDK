# Electrode ↔ Cortex Mapping

This subdirectory connects standardized EEG scalp positions to **approximate** underlying cortical anatomy and to practical EEG/BCI interpretation.

## Core rule

A scalp electrode does not measure one Brodmann area in isolation.

The observed voltage is influenced by:

- head and cortical geometry;
- skull/scalp conductivity;
- source orientation and depth;
- reference montage;
- volume conduction;
- electrode-placement error;
- individual anatomical variability;
- spatial mixing from multiple neural generators.

Therefore this project should use wording such as **“commonly projects near,” “often overlies,” “approximately associated with,”** or **“frequently used to sample activity related to”** rather than claiming an exact one-to-one electrode→BA identity.

## What this layer will connect

```text
EEG label
  ↓
scalp position
  ↓
likely anatomical projection(s)
  ↓

  ↓
functional network / experimental paradigm
  ↓
EEG feature or BCI use
```

## Planned mapping groups

Future maintenance can deepen one coherent group at a time, for example:

- frontopolar/prefrontal: Fp1/Fp2, AF-family, F-family;
- sensorimotor: C3/Cz/C4 and neighboring FC/CP positions;
- temporal/auditory: T/FT/TP families;
- parietal/attention: P/CP/PO families;
- visual/occipital: O1/Oz/O2 and PO-family;
- midline: Fz/FCz/Cz/CPz/Pz/POz/Oz;
- paradigm-specific sets for motor imagery, SSVEP, P300, auditory ERP, sleep and neurofeedback.

## Example of the correct interpretation style

A motor-imagery montage often emphasizes `C3`, `Cz`, `C4` because these scalp locations are near sensorimotor cortical regions and are useful for observing mu/beta rhythm modulation. That statement is scientifically safer than saying “C3 equals BA4.”

Likewise, occipital positions such as `O1`, `Oz`, `O2` are commonly used for visual EEG/SSVEP because they overlie posterior visual cortex, but an SSVEP recorded there is not generated by a single Brodmann area only.

## Evidence standard for future mapping tables

Before adding a mapping, prefer evidence from:

1. MRI/CT electrode-localization studies;
2. neuronavigation studies;
3. source-localization literature;
4. standard EEG atlases/guidelines;
5. reproducible template-coordinate resources;
6. paradigm-specific peer-reviewed EEG/BCI literature.

Each mapping should identify whether it is:

- **standard scalp position only**;
- **anatomical approximation**;
- **population/template mapping**;
- **individual MRI-confirmed localization**;
- **functional/paradigm association**.

Do not collapse these evidence levels into one certainty label.

## Useful foundational evidence

Homan, Herman and Purdy studied cerebral locations of International 10–20 positions and reported substantial variability for some electrode locations, supporting the need for caution when translating scalp labels into exact cortical anatomy.

Herwig and colleagues also evaluated 10–20 positions with neuronavigation for cortical targeting, illustrating that standard scalp positions can be useful anatomical guides while remaining approximate rather than individual-specific localization.
