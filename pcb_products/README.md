# ADS1299 PCB Products

This directory is reserved for future physical ADS1299 PCB/module releases associated with the ADS1299-Core-SDK project.

## Purpose

- Publish photos and revision information for physical ADS1299 PCB boards and modules.
- Provide hardware version identifiers, production notes, interface descriptions, and compatibility information.
- Link released hardware revisions to the corresponding open-source design files, firmware, documentation, and test results in this repository.
- Provide clear safety, research-use, licensing, and support information before any public listing or distribution.

## Planned contents

- `images/` — product and PCB photographs
- `revisions/` — hardware revision notes
- `manufacturing/` — production and assembly information intended for public release
- `testing/` — validation summaries and acceptance tests
- `release_notes/` — release history

> Status: Preparation area. No commercial availability or regulatory approval is implied by the presence of this directory.
