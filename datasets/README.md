# Datasets

Dataset notes, metadata and download/preparation scripts for EEG and BCI examples.

Large public datasets should normally **not** be committed directly to this repository. Keep the repository lightweight and reproducible by providing:

- dataset name and official source;
- license / citation requirements;
- expected channel montage and sampling rate;
- download or preparation instructions;
- checksums where appropriate;
- scripts that convert data into examples used by `eeg_analysis/` and `bci/`.

Planned sections:

- `eeg/` — general EEG analysis datasets.
- `bci/` — SSVEP, motor-imagery, P300 and other BCI datasets.
