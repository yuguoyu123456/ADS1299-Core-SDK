# Capability

| Item | Capability |
|---|---|
| CPU | 120 MHz Cortex-M4F |
| RAM | 256 KiB SRAM |
| Flash | 1 MiB Flash |
| SPI | SSI0 legacy Mode 1; PIOSC16 / 16 = 1 MHz |
| DMA | Yes |
| USB | USB OTG |
| BLE | No |
| Multi-ADS1299 | Multiple devices possible; Ethernet transport is available |

These are planning limits, not throughput evidence. Bench measurements decide
the final supported ADS1299 count and transport rate.
