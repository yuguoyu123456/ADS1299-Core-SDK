# Capability

| Item | Capability |
|---|---|
| CPU | up to 192 MHz |
| RAM | 160 KiB SRAM class |
| Flash | 512 KiB Flash class |
| SPI | SPI Mode 1 |
| DMA | PDMA |
| USB | USB HS/FS |
| BLE | No |
| Multi-ADS1299 | Template; validate resource budget |

These are planning limits, not throughput evidence. Bench measurements decide
the final supported ADS1299 count and transport rate.
