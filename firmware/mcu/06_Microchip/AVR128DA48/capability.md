# Capability

| Item | Capability |
|---|---|
| CPU | up to 24 MHz |
| RAM | 16 KiB SRAM |
| Flash | 128 KiB Flash |
| SPI | SPI Mode 1 |
| DMA | Event system; no general DMA |
| USB | No |
| BLE | No |
| Multi-ADS1299 | One device recommended; measure CPU and serial budget |

These are planning limits, not throughput evidence. Bench measurements decide
the final supported ADS1299 count and transport rate.
