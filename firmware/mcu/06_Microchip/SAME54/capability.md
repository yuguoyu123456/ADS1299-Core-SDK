# Capability

| Item | Capability |
|---|---|
| CPU | up to 120 MHz |
| RAM | 256 KiB SRAM |
| Flash | 1 MiB Flash |
| SPI | SERCOM SPI Mode 1 |
| DMA | DMAC |
| USB | USB HS/FS |
| BLE | No |
| Multi-ADS1299 | Multiple devices practical with DMAC |

These are planning limits, not throughput evidence. Bench measurements decide
the final supported ADS1299 count and transport rate.
