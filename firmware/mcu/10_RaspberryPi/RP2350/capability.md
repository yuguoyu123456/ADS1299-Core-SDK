# Capability

| Item | Capability |
|---|---|
| CPU | dual-core up to 150 MHz |
| RAM | 520 KiB SRAM |
| Flash | external QSPI Flash |
| SPI | SPI0 Mode 1; 4 MHz bring-up |
| DMA | Yes |
| USB | USB FS device/host |
| BLE | No |
| Multi-ADS1299 | PIO and dual cores enable multiple devices |

These are planning limits, not throughput evidence. Bench measurements decide
the final supported ADS1299 count and transport rate.
