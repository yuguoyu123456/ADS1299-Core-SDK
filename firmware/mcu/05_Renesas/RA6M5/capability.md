# Capability

| Item | Capability |
|---|---|
| CPU | up to 200 MHz |
| RAM | 512 KiB SRAM |
| Flash | up to 2 MiB Flash |
| SPI | SPI Mode 1; 1 MHz reference |
| DMA | DTC/DMAC hardware; reference adapter excludes DMA |
| USB | USB HS/FS |
| BLE | No |
| Multi-ADS1299 | One device reference; multi-device throughput unverified |

These are planning limits, not throughput evidence. Bench measurements decide
the final supported ADS1299 count and transport rate.
