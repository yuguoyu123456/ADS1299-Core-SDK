# Capability

| Item | Capability |
|---|---|
| CPU | up to 240 MHz RXv3 |
| RAM | 1 MiB RAM |
| Flash | 4 MiB Flash |
| SPI | RSPI Mode 1 |
| DMA | DMAC/DTC |
| USB | USB HS/FS |
| BLE | No |
| Multi-ADS1299 | Strong multi-device and Ethernet capability |

These are planning limits, not throughput evidence. Bench measurements decide
the final supported ADS1299 count and transport rate.
