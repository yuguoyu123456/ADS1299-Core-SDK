# Capability

| Item | Capability |
|---|---|
| CPU | up to 78 MHz |
| RAM | 256 KiB RAM |
| Flash | up to 1536 KiB Flash |
| SPI | EUSART SPI Mode 1 |
| DMA | LDMA |
| USB | No native USB on MCU |
| BLE | BLE / 802.15.4 |
| Multi-ADS1299 | Multiple devices possible; isolate radio timing |

These are planning limits, not throughput evidence. Bench measurements decide
the final supported ADS1299 count and transport rate.
