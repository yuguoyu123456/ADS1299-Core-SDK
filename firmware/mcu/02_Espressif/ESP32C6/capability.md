# Capability

| Item | Capability |
|---|---|
| CPU | high-performance core up to 160 MHz |
| RAM | 512 KiB HP SRAM |
| Flash | external module Flash varies |
| SPI | GPSPI Mode 1; start at 4 MHz |
| DMA | Yes |
| USB | USB Serial/JTAG |
| BLE | BLE 5 LE |
| Multi-ADS1299 | Multiple devices possible; radio coexistence needs buffering |

These are planning limits, not throughput evidence. Bench measurements decide
the final supported ADS1299 count and transport rate.
