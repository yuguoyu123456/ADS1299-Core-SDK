# Capability

| Item | Capability |
|---|---|
| CPU | 64 MHz Cortex-M4F |
| RAM | 256 KiB RAM |
| Flash | 1 MiB Flash |
| SPI | SPIM Mode 1 |
| DMA | EasyDMA |
| USB | USB FS |
| BLE | BLE 5 |
| Multi-ADS1299 | Multiple devices possible; keep BLE outside acquisition ISR |

These are planning limits, not throughput evidence. Bench measurements decide
the final supported ADS1299 count and transport rate.
