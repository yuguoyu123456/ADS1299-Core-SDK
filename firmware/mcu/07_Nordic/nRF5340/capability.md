# Capability

| Item | Capability |
|---|---|
| CPU | application core up to 128 MHz |
| RAM | 512 KiB application RAM |
| Flash | 1 MiB application Flash |
| SPI | SPIM Mode 1 |
| DMA | EasyDMA |
| USB | USB FS |
| BLE | BLE 5 |
| Multi-ADS1299 | Multiple devices practical; use network core separation |

These are planning limits, not throughput evidence. Bench measurements decide
the final supported ADS1299 count and transport rate.
