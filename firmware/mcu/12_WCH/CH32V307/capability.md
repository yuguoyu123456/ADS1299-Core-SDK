# Capability

| Item | Capability |
|---|---|
| CPU | up to 144 MHz |
| RAM | 64 KiB SRAM |
| Flash | 256 KiB Flash |
| SPI | SPI1 Mode 1 |
| DMA | DMA |
| USB | USB HS/FS |
| BLE | No |
| Multi-ADS1299 | Multiple devices possible |

These are planning limits, not throughput evidence. Bench measurements decide
the final supported ADS1299 count and transport rate.
