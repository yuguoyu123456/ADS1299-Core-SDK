# Capability

| Item | Capability |
|---|---|
| CPU | up to 150 MHz |
| RAM | 320 KiB SRAM |
| Flash | 640 KiB Flash |
| SPI | SPI7 Mode 1; FRO12 / 12 = 1 MHz |
| DMA | Yes |
| USB | USB HS/FS |
| BLE | No |
| Multi-ADS1299 | Multiple devices possible with per-device CS |

These are planning limits, not throughput evidence. Bench measurements decide
the final supported ADS1299 count and transport rate.
