# Capability

| Item | Capability |
|---|---|
| CPU | Cortex-M7 up to 1 GHz plus Cortex-M4 up to 400 MHz |
| RAM | 2 MiB on-chip RAM |
| Flash | external boot Flash on EVKB |
| SPI | LPSPI1 Mode 1; 4 MHz bring-up |
| DMA | eDMA available; reference adapter is blocking |
| USB | two USB 2.0 OTG controllers with integrated PHYs |
| BLE | optional M.2 Wi-Fi/BLE module; no integrated radio |
| Multi-ADS1299 | One device reference; multi-device requires separate CS/DRDY and measured scheduling |

These are planning limits, not throughput evidence. Bench measurements decide
the final supported ADS1299 count and transport rate.
