# Capability

| Item | Capability |
|---|---|
| CPU | up to 200 MHz |
| RAM | 192 KiB SRAM in validated board profile |
| Flash | 3 MiB Flash in validated board profile |
| SPI | SPI Mode 1 |
| DMA | DMA |
| USB | USB HS/FS |
| BLE | No |
| Multi-ADS1299 | Multiple devices practical |

These are planning limits, not throughput evidence. Bench measurements decide
the final supported ADS1299 count and transport rate.
